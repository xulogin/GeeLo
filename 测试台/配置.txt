# ---- 2. 代理（一般不用填）---------------------------------------
#
# 程序会**自动寻找**能连通 Google 的方式：
#     先试直连 -> 不通就扫本机常见代理端口（10808/10809/7890/7897/1080...）
#     -> 找到能用的就自动使用
#
# 所以这一行通常留着不动就行。
#
# 只有两种情况需要填：
#   1) 你的代理端口不在常见范围内；
#   2) 每次都要扫端口太慢，想固定下来。
#
# 填法（去掉行首的 # 号）：
#
# 代理 = http://127.0.0.1:10808
#
# 端口在代理软件设置里看（找「HTTP 代理端口」或「混合端口」）。
